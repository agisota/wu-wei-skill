# Wu-Wei Rewriter Skill — русское описание

См. основной `README.md`: он начинается с трёх before/after примеров на английском, русском и китайском, а затем объясняет концепцию и установку. Этот файл оставлен как русская точка входа для каталогов, которые ожидают отдельный локализованный README.

Коротко: это skill для переписывания тезисов, pitch, hypotheses, frameworks и recommendations через ограничения: область применимости, falsifiable predictions, killed claims, polarity notes, elegance audit и Frame Log.
